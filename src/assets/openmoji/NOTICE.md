# OpenMoji artwork

Every `.svg` in this directory is unmodified OpenMoji artwork.

- Project: **OpenMoji** — the open-source emoji and icon project, <https://openmoji.org>
- Licence: **CC BY-SA 4.0** — <https://creativecommons.org/licenses/by-sa/4.0/>
- Fetched by `scripts/fetch-openmoji.mjs`, which also records the code point
  each file came from.

The licence is share-alike: if you change one of these files, the changed file
carries CC BY-SA 4.0 too. The app credits OpenMoji in its footer and in the
README, which is what the attribution clause asks for.
